# استاندارد بازی‌های قربانی کیدز

## ۱. ارسال امتیاز به سیستم قربانی کیدز:
در نقطه پایان بازی، گیم اور شدن، یا محاسبه امتیاز نهایی، حتماً این قطعه کد باید اجرا شود:
```javascript
if (window.parent) {
    window.parent.postMessage({
        type: 'GK_SUBMIT_SCORE',
        score: finalScore // متغیر امتیاز عددی
    }, '*');
}
```

## ۲. مراحل افزودن بازی:
1. آماده‌سازی فایل `index.html` و متعلقات.
2. درج قطعه کد `postMessage` فوق در رویداد اتمام بازی.
3. آپلود در مسیر `wp-content/games/[game-slug]/` در هاست.
4. ثبت در پیشخوان وردپرس > منوی بازی‌ها > افزودن بازی (وارد کردن عنوان و نام پوشه بازی).
