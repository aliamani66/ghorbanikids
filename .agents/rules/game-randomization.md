# قانون تصادفی‌سازی و عدم پیش‌بینی‌پذیری گزینه‌ها در بازی‌ها (Game Design Randomization & Anti-Pattern Rule)

این قانون برای تمام بازی‌های آموزشی، آزمون‌ها و تمرین‌های تعاملی قربانی کیدز الزامی است:

---

## ۱. تصادفی‌سازی کامل چینش گزینه‌ها (Options Shuffle):
- ترتیب گزینه‌های چندگزینه‌ای در هر مرحله یا هر دور بازی باید به صورت ۱۰۰٪ تصادفی با الگوریتم **Fisher-Yates Shuffle** برهم بخورد.
- پاسخ صحیح نباید همیشه در گزینه اول، وسط یا آخر باشد.

## ۲. تصادفی‌سازی ترتیب سوالات و چالش‌ها (Questions & Rounds Pool Randomization):
- در هر بار شروع مجدد بازی (`بازی مجدد`)، ترتیب سوالات و آیتم‌ها باید کاملاً تصادفی و غیرقابل پیش‌بینی باشد.
- از ایجاد توالی‌های یکی‌در‌میانی (مثل: بله/خیر، درست/نادرست، جذب می‌شود/نمی‌شود) اکیداً خودداری شود تا کودک نتواند با الگویابی مکانی یا ریتمی، بدون فکر کردن امتیاز بگیرد.

## ۳. جابجایی حروف، کلمات و دکمه‌های تعاملی:
- در بازی‌های وصل‌کردنی، جمله‌سازی، مرتب‌سازی و انتخاب حروف (مانند جدول دوستی یا صدای اول/آخر)، دکمه‌ها و حروف در هر راند در موقعیت‌های متفاوتی قرار گیرند.

## نمونه کد استاندارد شافل در جاوااسکریپت:
```javascript
function shuffleArray(array) {
    var arr = array.slice();
    for (var i = arr.length - 1; i > 0; i--) {
        var j = Math.floor(Math.random() * (i + 1));
        var temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }
    return arr;
}
```
